# ExaPolymer — передача проекта Claude

Полный исходный проект сайта инженерных полимеров.

## Что находится в проекте

- многостраничный сайт на Next.js / Vinext;
- каталог из 9 материалов и 29 марок;
- фотографии продукции и работ;
- фильтры и сравнение материалов;
- страницы материалов и отдельных марок;
- страницы контактов, поставки и информации о проекте;
- адаптивная мобильная версия.

## Запуск

Требуются Node.js и pnpm.

```bash
pnpm install
pnpm dev
```

Проверка производственной сборки:

```bash
pnpm build
```

## Основные папки

- `app/` — страницы, компоненты, стили и каталог;
- `public/` — фотографии и социальное превью;
- `.openai/hosting.json` — конфигурация размещения в Sites.
